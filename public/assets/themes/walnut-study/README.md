# Walnut Study assets

`board-surface.webp` is the current Walnut Study gameplay surface.

`card-back.png` is the active standard card-back for Walnut Study: a resized 432 × 604 transparent PNG with rounded transparent outer corners, used in gameplay instead of the older SVG placeholder.

`shop-card-back.png` is a small derivative preview of the same back design for possible UI/catalog use.

The older `card-back.svg` remains in the folder only as a legacy placeholder and is no longer used by the active theme registry.
