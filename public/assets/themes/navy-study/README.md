# Navy Study

Authored gameplay theme for Cascade Solitaire.

- `board-surface.webp` — full top-down navy study composition rendered as one `cover` surface; no nine-slice and no central compass graphic.
- `card-back.webp` — approved production back normalized to 432×604 with the shared rounded transparent card contour preserved; runtime uses the full image with no crop.
- `shop-card-back.webp` — 165×230 preview derived from the approved rounded transparent back.
- Slots use the shared runtime frame + glyph system with Navy Study palette values from `ThemeRegistry.ts`.
- Gameplay layout, card faces, HUD geometry, and interaction behavior are unchanged.
