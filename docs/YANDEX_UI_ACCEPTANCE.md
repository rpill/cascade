# Интерфейс, настройки и проверка Яндекс Игр

Проверено по [требованиям Яндекс Игр](https://yandex.ru/dev/games/doc/ru/concepts/requirements) и [инструкции автоопределения языка](https://yandex.ru/dev/games/doc/ru/requirements/2/14), 9 сентября 2026.

| Требование | Реализация / проверка |
| --- | --- |
| 2.14: язык через SDK при запуске | Читается `environment.i18n.lang`; русский для ru/be/kk/uk/uz, английский для остальных. Ручной выбор сохраняется. |
| 6.1: отключение звука | Переключатель в настройках управляет общим mute Phaser. |
| 1.3 и паузы платформы | Аудио отключается при blur, скрытии страницы, pagehide и `game_api_pause`; включение пользователем не обходит эти состояния. |
| 1.6: интерфейс на заявленных устройствах | Проверяются десктоп, горизонтальные и вертикальные телефоны, отступы, доступность кнопок и прокрутка каталога. |
| 1.6.1.8: контекстное меню | Блокируется на игровом контейнере; прокрутка каталога остаётся доступной. |
| 1.19: Ready / игровой жизненный цикл | Сохранены существующие адаптеры готовности, паузы и GameplayAPI. |

Перед публикацией остаются реальные проверки в черновике: SDK debug-панель с RU/EN на чистом профиле; полноэкранное отображение на заявленных мобильных устройствах; звук и паузы при настоящей рекламе; cloud save и таблицы лидеров. Нужна также сверка названия, локализованных промоматериалов и заявленных языков в Консоли. Локальные тесты не подтверждают прохождение модерации.

## Локальные команды

`pnpm test` и `pnpm build`.

При работающем Vite: `node tests/browser/menu-runtime.mjs`, `node tests/browser/settings-runtime.mjs`, `node tests/browser/economy-runtime.mjs`, `node tests/browser/economy-edgecases.mjs`. Переменные `CASCADE_URL` и `PLAYWRIGHT_MODULE` задают адрес приложения и путь к Playwright. Browser fixtures изолированы от пользовательского профиля. Скриншоты и логи находятся в `artifacts/`.

## Границы реализации

Игра пока не содержит музыкальных дорожек или звуковых эффектов; настройка уже подключена к настоящему звуковому менеджеру Phaser и применяется к будущим звукам. Язык и звук — настройки устройства (`cascadePreferences`), они не смешиваются с облачной экономикой. Смена языка не перезагружает страницу, не создаёт новую раздачу и не сбрасывает Undo.
