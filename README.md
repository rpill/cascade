# Cascade Solitaire

Минимальный Phaser-прототип пасьянса с механикой Sawayama Solitaire.

## Что уже работает

- оригинальная схема поля: четыре базы слева, колода над первым столбцом,
  сброс веером вдоль верхней строки;
- стартовая раздача по одной карте и открытие колоды по три карты с анимацией;
- перенос одной карты и упорядоченных убывающих цепочек drag-and-drop;
- сбор баз по масти от туза до короля;
- свободная ячейка на месте опустевшей колоды;
- возврат карты на исходное место после недопустимого сброса;
- двойное нажатие по доступной карте отправляет её в базу;
- рестарт той же раздачи кнопкой или клавишей `R`;
- новая случайная раздача отдельной кнопкой `НОВАЯ ИГРА`;
- уведомление `LoadingAPI.ready()` при запуске внутри Яндекс Игр.

Раздача повторяет найденное в исходниках Hikone стартовое ограничение: среди
семи открытых карт нет тузов и сразу совместимых разномастных пар соседних
рангов. Сам оригинал не запускает полный решатель и не гарантирует математическую
решаемость каждой партии.

## Структура

- `src/game/model` — чистые правила, карты и генерация раздачи без Phaser;
- `src/game/view` — геометрия поля, карточные объекты, ввод и анимации;
- `src/game/scenes` — загрузка и координация игрового состояния;
- `src/platform` — изолированная интеграция с игровой платформой.

## Запуск

```bash
pnpm install
pnpm dev
```

Проверки и production-сборка:

```bash
pnpm test
pnpm build
```
